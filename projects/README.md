## How to use
1. Clone the repo.
2. From the workshop site, open a challenge → fill the brief → **Copy GitHub**.
3. Paste into Cursor Agent — it will target the matching `projects/<slug>/` path.

Or open any `projects/<slug>/index.html` directly in a browser.
